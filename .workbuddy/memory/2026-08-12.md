## content/projects 添加 hello-agents 不显示的问题
- 根因（双重）：① 缺少 `index.md`，Hugo 不把它当项目页面；② 把整个 git 仓库塞进 `content/projects/hello-agents/`，Hugo 把 `echarts.html` 当内容页被 `security.allowContent` 拒绝，**整站构建失败**（连 projects 列表都不生成）；③ 该目录还被 git 登记为 **submodule gitlink**（mode 160000），导致 index.md 无法作为普通文件提交。
- 修复：创建 `content/projects/hello-agents/index.md`（front matter: title/date/description/status/featured/emoji/tags/link，link 指向 datawhalechina.github.io/hello-agents）；把整仓内容移到站外 `D:/workspace/_archive_hello-agents/`（不删）；`git rm --cached -f` 解除 gitlink 后重新 add index.md。
- 经验：**content/ 目录只放页面文件(.md)，不要把整个 git 仓库直接塞进 content**（会触发 submodule 注册 + .html 安全策略报错导致整站构建失败）。新增项目只需放一个带 front matter 的 `index.md`。
- 已提交并推送 `1d3b732`。

## git push 失败（Connection reset port 22）修复
- 根因：SSH 22 端口直连 GitHub 被网络重置（大陆常见）。
- 方案：`~/.ssh/config` 增加 `Host github.com / Hostname ssh.github.com / Port 443 / User git`，让 git 走 443 端口（已验证 ssh.github.com:443 可认证）。
- 验证：`git push origin master` 成功（`2c500a9..1d3b732`）。

## 前端美化与优化：响应式设计 + 交互体验 + 可访问性
- 背景：用户要求前端界面美化优化，要求响应式设计和良好用户交互体验。FrontendDeveloper 专家分析并实施。
- 分析发现 6 类问题：死 CSS 残留、断点不一致(900/768/720/640/1180混用)、可访问性缺失(无skip链接/无全局reduced-motion)、交互缺口(无返回顶部/无当前页高亮)、移动端导航幽灵样式(768px定义.nav但DOM中已不存在)、性能(3452行CSS未拆分)。

- 改动 1 — 清理死 CSS（`assets/css/main.css`）：
  - 移除旧导航样式：`.nav-wrap`、`.logo`、`.logo-dot`、`@keyframes pulse`、`.nav`、`.nav-link`(含::after/hover)、`.nav-actions`、`.theme-toggle,.nav-burger` 基础块、`.nav-burger{display:none}`。
  - 移除 `@media(max-width:768px)` 中 `.nav`/`.nav.open`/`.nav-link`/`.nav-burger` 的移动端幽灵菜单样式（DOM 中已无这些元素）。
  - 移除文件后段重复的 `.site-header` + `.site-header .theme-toggle` 重复定义块（约 2094 行处），只保留首段定义。
  - CSS 净减约 100 行死代码。

- 改动 2 — 可访问性（`layouts/_default/baseof.html` + `assets/css/main.css`）：
  - baseof.html 添加 `<a href="#main" class="skip-link">跳转到主内容</a>`，`<main>` 加 `id="main"`。
  - CSS 新增 `.skip-link` 样式（fixed 定位、focus 时 top:16px 滑入）。
  - 新增全局 `:focus-visible` 样式（2px solid accent outline + offset）。
  - 新增全局 `@media(prefers-reduced-motion:reduce)` 覆盖：所有 animation/transition → 0.01ms，`.tech-track`/`.avatar-smoke-img`/`.typing-cursor` 等动画全部停止。
  - header.html 的 music-toggle 按钮加 `aria-expanded="true"` 属性。

- 改动 3 — 响应式设计增强（`assets/css/main.css` 新增约 200 行）：
  - 统一断点体系：1180 / 1024 / 900 / 640 / 480px，新增 1024 和 480 两个断点。
  - `@media(≤1024px)`：container max-width 920px、bento 左列缩 220px、resource 三栏改两栏+insights 横排。
  - `@media(≤900px)`：nav-cards 2 列、resource sidebar/feed/insights 改纵向流并重排顺序、feed 取消固定高度。
  - `@media(≤640px)`：body 字号 15px、hero 头像缩 120px、nav-cards 1 列、post-nav 纵向、music-player 缩 180px。
  - `@media(≤480px)`：极小屏 hero 头像 104px、字号进一步缩小、resource-card padding 缩。
  - `@media(hover:none) and (pointer:coarse)`：触摸设备 page-nav-menu 始终可见（不用 hover）、卡片 hover transform 禁用。

- 改动 4 — 用户交互增强（`assets/js/main.js` 新增约 100 行）：
  - `initScrollTop()`：动态创建 `.scroll-top` 按钮，滚动超 400px 显示，点击 smooth scroll 回顶。
  - `initNavHighlight()`：根据 `window.location.pathname` 匹配 `.page-nav-menu a`，加 `.is-current` + `aria-current="page"`。
  - `initScrollReveal()`：IntersectionObserver 对 `.project-card/.post-card/.nav-card/.resource-card` 等加 `.reveal` → `.is-revealed` 淡入上移动画；prefers-reduced-motion 时跳过。
  - `initMusicAriaSync()`：MutationObserver 监听 music-player class 变化，同步 music-toggle 的 `aria-expanded`。
  - CSS 新增 `.scroll-top`、`.page-nav-menu a.is-current`、`.reveal/.is-revealed`、`@keyframes page-fade-in`、`.main{animation:page-fade-in}`。

- 验证：`hugo --destination .hugo_check --noBuildLock` 构建成功（33 Pages），确认 minified CSS 含 `scroll-top/skip-link/reveal/is-current/page-fade-in`，fingerprinted JS 含 13 处新函数名，HTML 含 `<a class="skip-link">` 和 `<main id="main">`。已 `cp -r` 到 public/。
