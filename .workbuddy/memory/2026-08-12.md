## content/projects 添加 hello-agents 不显示的问题
- 根因（双重）：① 缺少 `index.md`，Hugo 不把它当项目页面；② 把整个 git 仓库塞进 `content/projects/hello-agents/`，Hugo 把 `echarts.html` 当内容页被 `security.allowContent` 拒绝，**整站构建失败**（连 projects 列表都不生成）；③ 该目录还被 git 登记为 **submodule gitlink**（mode 160000），导致 index.md 无法作为普通文件提交。
- 修复：创建 `content/projects/hello-agents/index.md`（front matter: title/date/description/status/featured/emoji/tags/link，link 指向 datawhalechina.github.io/hello-agents）；把整仓内容移到站外 `D:/workspace/_archive_hello-agents/`（不删）；`git rm --cached -f` 解除 gitlink 后重新 add index.md。
- 经验：**content/ 目录只放页面文件(.md)，不要把整个 git 仓库直接塞进 content**（会触发 submodule 注册 + .html 安全策略报错导致整站构建失败）。新增项目只需放一个带 front matter 的 `index.md`。
- 已提交并推送 `1d3b732`。

## git push 失败（Connection reset port 22）修复
- 根因：SSH 22 端口直连 GitHub 被网络重置（大陆常见）。
- 方案：`~/.ssh/config` 增加 `Host github.com / Hostname ssh.github.com / Port 443 / User git`，让 git 走 443 端口（已验证 ssh.github.com:443 可认证）。
- 验证：`git push origin master` 成功（`2c500a9..1d3b732`）。
