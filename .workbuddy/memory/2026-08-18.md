# 2026-08-18 工作日志

## 修复「每日一句」循环按钮点击无反应
现象：首页右上角诗句下方的圆形刷新按钮单击无反应，且诗句始终停在静态兜底句。

根因（两处）：
1. **数据二次编码**：`layouts/index.html` 用 `{{ hugo.Data.quotes.items | jsonify }}` 注入名句库，但本机 Hugo v0.164.0 对 `hugo.Data` 下的 slice 做 `jsonify` 会输出成**带引号的 JSON 字符串**（即 `"[{...}]"`），`JSON.parse` 得到 string 而非 array，`initHeroQuote` 在 `Array.isArray` 守卫处直接 return → 静态兜底、按钮无事件。
   - 修复：改为裸输出 `{{ hugo.Data.quotes.items }}`（不加 jsonify），产物即为合法 JSON 数组。
2. **boot() 无容错**：`initVisitorStats` 直接 `fetch(...)` 未守卫，一旦抛错会中断整个 `boot()`，导致排在最后的 `initHeroQuote` 不执行。
   - 修复：`boot()` 内所有 init 改为 `safe(label, fn)` 包裹，单点失败不再连累后续。

改动文件：`layouts/index.html`（hero-quotes-data 去 jsonify）、`assets/js/main.js`（initHeroQuote 解析容错 + boot 加 safe 包裹）、`data/quotes.yaml`（名句整体包到 `items:` 键下，便于 hugo.Data.quotes.items 取出）。

验证：hugo --noBuildLock 构建通过；用 jsdom 加载产物模拟点击，dailyQuote 正确应用、点击后切换成功、无 JS 报错。
